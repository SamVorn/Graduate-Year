
## Pumping on CFL
- If L is a CFL => L has property P
- for every string coming from the language p >=1 where |s|>=p
- S can be divided into five parts, s=uvxyz, satisfing three conditions
1. uv^ixy^iz element of L for each i>=0
2. |vy|>0
3. |vxy| <= p
