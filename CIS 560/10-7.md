# Chomsky Normal Form (CNF)
```
A -> BC
A -> a
```
- If S is a start variable
1. S cannot appear at the right hand side
2. epsilon - value is only allowed for S
    - S -> epsilon
3. Can only have two variables on the right hand side
```
S -> AB
A -> a
B -> b

Is this in CNF?
Yes
```
```
S -> AB
A -> a
B -> epsilon

is it in CNF?
No
```
```
S -> aS|a

CNF?
no
```

- Any CFG can be converted into CNF
- Any CFL (context free language) is generated by a CFG in CNF
- By definition any context free language can be generated by context free grammar
