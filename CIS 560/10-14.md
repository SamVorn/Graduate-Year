# Pumping Lemma for CFG to prove Irregularity
L={a^nb^nc^n | n >= 0}

To prove this is irregular we need to use the pumping lemma for context free languages

```
Assume : is context free => L has property p
Let s=a^pb^pc^p
|s| = 3p >= p
s = uvxyz such that |vxy| <= p

1. When vxy consists of only a's, b's, or c's
pump up s
number of a's b's c's in the new string are not equal, and therefore the new string does not belong to the language

2. when vxy is a substring of a^pb^p
pump up s. the new string uv^2xy^2z, contains less c's than a's and/or b's

3. when vxy is a substring of b^pc^p
pumping up s, the new substring will contain less a's than b's or c's

s cannot be pumped => this is a contradiction 
```
