## What is a context free grammar
- A CFG is a 4-tuple, where 
1. V is a finite set of variables
2. Sigma is a finite set of symbols/terminals
3. R is a finite set of rules
    - A -> X
    - A E V, X E(V U sigma)*
4. S E V is the start variable

## 1. Union of Two Languages

## 2. If the language is regular => CFG
- Design a DFA/NFA
1. Define a variable Ri for eac state qi
2. Add a rule Ri -> aRj if Delta(qi a) = qj
3. add a rule Ri -> Epsilon if qi is an accept state
4. if qi is the start state, R1 is the start variable
