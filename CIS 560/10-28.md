# Church Turing Thesis
- any problem that can be solved by an algorithm can be solved by a turing machine
- given an algorithm there is a turing machine that exists to solve said problem
    - algorithm -> TM
    - this is a solvable problem or a decidable
- if no turing machine exists to solve a particular problem, there is no algorithm
    - no algorithm <- no TM exists
    - unsolvable/undecidable

- Given two context free grammars G1 and G2
