# C to MIPS Assembly Examples

A single line of C may break up into several lines of MIPS
```
a = b+c (in C)
> Add $s0, $s1, $s2 (in mips)
```

```
a = b + c + d - e;
> add $t0, $s1, $s2
> add $t0, $t0, $s3
sub $s0, $to, $s1
```
## Logical Operators
- Instruction Names:
    - and, or : both of these expect the third argument to be a register
    - andi, ori : both of these expect the third argument to be an immediate (what is an immediate)
- MIPS logical operators are all bitwise, meaning that the bit 0 of the output is produced by the respective bit 0's of the inputs, bit 1 by the bit 1's, etc
- MIPS also has xor, xori, nor instructions

```
Note that anding a bit with 0 produces 0 at the output while anding a bit with 1 produces the original bit
```
- this can be used to create a mask
