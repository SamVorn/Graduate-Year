## Implementing MIPS
### Stages of the Datapath
- there is a wide variety of MIPS instructions: so what general steps do they have in common
1. instruction fetch
    - no matter what the instruction the 32 git instruction word must first be fetched from memory
    - this is also where we increment pc
2. Instruction Decode
    - read the opcode to determine instruction type and field lengths
    - upon fetching the instruction gather the data from the fields
    - second, read in data from all necessary registers
        - for add, read two registers
        - for addi read one register
3. ALU work: arithmetic, logic, comparison, offset
4. Memory Access: only load and store
5. Register Write: update if this is an add instruction
