# Instruction level parallelism
2 instructions are:
1. parallel: they can execute simultaneously in a pipeline of arbitrary depth without causing stalls
2. dependent: they are not parallel and must be executed in order, although they may often partially overlap

> A stall caused by a dependence is a hazzard

- if two instructions are data dependent, they cannot be completely overlapped or execute simultaneously
- HW/SW must preserve program order (semantics)
    - determined by source code
    - implies data flow and calculation order
- Dependence indicates potential hazard
    - actual hazard and length of any stall is property of the pipeline (HW)

## Name Dependence
- 2 instructionso use the same register or memory location, but no data flow between instructions associated with that name
- name dependencies only cause problems if order is changed
